Privacy Policy

Last updated: 1 November 2026

This policy covers SBP Uploader (also called the SBP Dashboard), a private tool used by the owner of the YouTube channel Your Surviving Job to upload and schedule the channel's own videos. It is not a public service: it runs only on the channel owner's own computer, and the only Google account that signs in to it is the channel owner's.

What the app does

The app uses the YouTube Data API to upload the channel's finished videos, Shorts and thumbnails, set their titles, descriptions, tags, playlists and publish times, and read back the status of those uploads. It acts only on the signed-in owner's own channel.

Google user data the app accesses

  • YouTube upload and management (scopes youtube.upload and youtube): to upload the owner's videos and thumbnails, update their details, add them to the owner's playlists, and check their processing and publish status.
  • Basic channel information (channel name and id): to show which channel is connected.

The app does not read, collect or process data about any other YouTube user, viewer or commenter.

How the data is stored

After the owner signs in, Google returns an OAuth token. The app stores this token in a local file on the owner's computer and uses it only to call the YouTube Data API on the owner's behalf. Upload results (video ids, links, publish dates) are stored in local project files on the same computer. Nothing is stored on any server run by the app; there is no such server.

Sharing

The app does not sell, share, transfer or disclose Google user data to anyone. Data is sent only to Google's own YouTube API, as needed to perform the uploads the owner requests. The app has no analytics, advertising or tracking.

Limited Use

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting data

The token is kept until the owner disconnects the app. The owner can revoke the app's access at any time at myaccount.google.com/permissions and delete the local token file; after that the app can no longer access the account.

This website

This website is a static page. It sets no cookies and runs no analytics. The hosting provider may keep standard server logs (such as IP addresses) for security and operation.
